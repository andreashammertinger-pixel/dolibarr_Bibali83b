# Uplate i stanje plaćanja

## Unos uplate

Uplatu vlasnika potrebno je **povezati sa zaduženjem** – samo tada se udio pričuve automatski prenosi.

- **na računu:** otvoriti račun → *Unesi uplatu* → iznos, datum, bankovni račun zajednice
- **pri usklađivanju banke:** bankovnu stavku povezati s računom

!!! info "Automatski prijenos pričuve"
    Pri unosu uplate modul prenosi udio pričuve s bankovnog računa zajednice na **račun pričuve kuće** (npr. *Rezerve-Kuća1*). Kod djelomične uplate razmjerno. Ako se uplata obriše, poništava se i prijenos.

!!! warning
    Bankovna stavka **bez** veze s računom ne pokreće prijenos pričuve, a račun ostaje otvoren.

## Stanje plaćanja

*Upravljanje zgradom → Stanje plaćanja*

Po apartmanu: ukupno zaduženje, **dospjelo do danas** (prema planu rata), plaćeno, **zaostatak**, sljedeća rata. Zaostaci su označeni crveno.

## Preplata iz godišnjeg obračuna

Preplata se automatski oduzima pri izradi sljedećih zaduženja (redak *uračunata preplata*). Vidi [Godišnji obračun](jahresabrechnung.md).
