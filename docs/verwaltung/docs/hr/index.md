# Priručnik za upravljanje zgradom

Ovaj priručnik objašnjava rad s Dolibarr modulom **Hausverwaltung (upravljanje zgradom)**: izradu i slanje zaduženja, uplate i pričuvu, godišnji obračun te rad s vlasnicima.

!!! tip "Pomoć izravno iz Dolibarra"
    Na svakoj stranici modula **upitnik gore desno** vodi izravno na odgovarajuće poglavlje ovog priručnika – na Vašem jeziku.

## Načelo u jednoj rečenici

**Zajednica suvlasnika** (npr. *Zgrada Bibali 83B*) svakom apartmanu mjesečno zadužuje **zajedničke troškove**, **pričuvu** i **upravljanje** – izračunato prema stambenoj površini (m²). Svi dokumenti postoje na **hrvatskom** i na **jeziku vlasnika** – prijevodi pomoću AI s izvornog jezika (uglavnom njemačkog).

## Godišnji tijek

| Kada | Što | Poglavlje |
|---|---|---|
| **studeni / prosinac** | provjeriti plan troškova za sljedeću godinu, donijeti godišnji program održavanja, izraditi i poslati zaduženje **01–12** za sljedeću godinu | [Troškovi](kosten.md), [Zaduženje](vorschreibung.md) |
| **tijekom godine** | unositi ulazne račune s vrstom troška, uplate vlasnika povezivati s računom | [Troškovi](kosten.md), [Uplate](zahlungen.md) |
| **nakon dospijeća** | provjeriti stanje plaćanja, kod zaostatka kontaktirati vlasnika | [Uplate](zahlungen.md) |
| **siječanj / veljača** | knjižiti godišnji obračun prethodne godine, poslati obračunske listove | [Godišnji obračun](jahresabrechnung.md) |
| **jednom godišnje** | pregled zgrada, ažurirati plan pričuve | [Pričuva](ruecklage.md) |

!!! warning "Rokovi prema hrvatskim propisima"
    Ako godišnji odnosno višegodišnji program nije donesen, vlasnici plaćaju pričuvu u **peterostrukom iznosu**. Detalji i izvori: [Novosti i propisi](news/index.md).

## Izbornik modula

| Stavka | Namjena |
|---|---|
| Pregled / raspodjela | mjesečni iznosi po apartmanu, stope po kući, upozorenja |
| Zgrade | kuće s računom pričuve i proizvodom pričuve |
| Apartmani | jedinice s m², vlasnicima, osiguranjem kućanstva |
| Plan troškova | vrste troškova s iznosom, razdobljem, zgradom i ključem raspodjele |
| Izradi zaduženja | zaduženja za jedan mjesec ili razdoblje |
| Slanje zaduženja | e-pošta vlasnicima sa svim privicima |
| Okružnice | obavijest svim ili odabranim vlasnicima, prevedena, s prilozima |
| Stanje plaćanja | tko je što platio, zaostaci |
| Pričuva / Plan pričuve | stanja računa, promjene, višegodišnji plan |
| Godišnji obračun | stvarni troškovi naspram akontacija, obračunski listovi |
| Mobilni unos | ulazne račune fotografirati i unijeti mobitelom |
| Jezici | provjera i dopuna prijevoda dokumenata |
