# Pričuva

## Računi i promjene

Svaka kuća ima vlastiti **račun pričuve** (bankovni račun u Dolibarru) i proizvod pričuve. *Upravljanje zgradom → Pričuva* prikazuje stanje i promjene po kući:

- **priljevi**: automatski pri svakoj uplati zaduženja (udio pričuve),
- **odljevi**: ulazni računi s oznakom *plaćeno iz pričuve*.

## Plan pričuve

*Upravljanje zgradom → Plan pričuve*

Višegodišnji plan održavanja (fasada, krov, priključak na kanalizaciju …) po kući ili za sve kuće. Projekcija računa s:

- početna vrijednost = trenutačno stanje računa,
- uplate = trenutačne stope,
- rast troškova gradnje (standard 3 % godišnje),
- razdoblje planiranja (standard 20 godina).

Rezultat po kući: najniže stanje, godina manjka i **minimalna stopa prema planu**. Ako je trenutačna stopa viša, pričuva je dovoljna.

!!! tip "Godišnji pregled"
    Nakon godišnjeg pregleda zgrada prilagoditi stavke (godina, iznos). Projekcija se odmah preračunava; objašnjenje zaduženja prikazuje sljedeće mjere.

**Prikaz za ispis** (gumbi *Prikaz za ispis HR, DE, …*) na svakom jeziku – kao prilog za sastanak suvlasnika.

**Uvoz**: JSON datoteka sa stavkama plana (višejezično). Kvačica *zamijeni postojeće stavke plana* sprječava dvostruki unos.
