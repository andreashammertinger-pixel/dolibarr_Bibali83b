# Godišnji obračun

*Upravljanje zgradom → Godišnji obračun* – do **kraja veljače** za prethodnu godinu.

## Izračun

- **Stvarni troškovi** = ovjereni ulazni računi godine s vrstom troška (bez *plaćeno iz pričuve*), raspodijeljeni prema ključu vrste troška.
- **Akontacije** = zajednički troškovi zaduženi u zaduženjima.
- **Saldo** = akontacije − stvarni troškovi → preplata ili nedoplata.

Pričuva i upravljanje se **ne** obračunavaju.

## Postupak

1. Odabrati godinu, provjeriti tablicu (jesu li svi ulazni računi uneseni i ovjereni?).
2. **Knjiži obračun** – vrijednosti se zaključavaju:
    - **nedoplata** → zaseban račun apartmanu,
    - **preplata** → uračunava se u sljedeća zaduženja.
3. **Izradi obračunske listove** – po apartmanu jedan PDF (hrvatski + kopija) sa svim vrstama troška, udjelom, akontacijama i saldom.
4. Testno slanje na vlastitu adresu, zatim **Pošalji obračunske listove vlasnicima** (račun za nedoplatu je u privitku).

Obračunski listovi nalaze se i u **dokumentima apartmana** – ondje ih vlasnik vidi u svom pristupu.
