# Handbuch Hausverwaltung

Dieses Handbuch erklärt die Arbeit mit dem Dolibarr-Modul **Hausverwaltung**: Vorschreibungen erstellen und versenden, Zahlungen und Rücklagen verwalten, die Jahresabrechnung erstellen und die Eigentümer betreuen.

!!! tip "Hilfe direkt aus Dolibarr"
    Auf jeder Seite der Hausverwaltung führt das **Fragezeichen oben rechts** direkt zum passenden Kapitel dieses Handbuchs – in Ihrer Sprache.

## Das Prinzip in einem Satz

Die **Gemeinschaft** (z. B. *Zgrada Bibali 83B*) schreibt jedem Apartment monatlich **Betriebskosten**, **Rücklage** und **Verwaltung** vor – berechnet nach der Wohnfläche (m²). Alle Dokumente gibt es im **kroatischen Original** und als **Kopie in der Sprache des Eigentümers**.

## Jahresablauf

| Wann | Was | Kapitel |
|---|---|---|
| **November / Dezember** | Kostenplan für das Folgejahr prüfen, Jahresprogramm (*godišnji program održavanja*) beschließen lassen, Vorschreibung **01–12** des Folgejahres erstellen und versenden | [Kosten](kosten.md), [Vorschreibung](vorschreibung.md) |
| **laufend** | Eingangsrechnungen mit Kostenart erfassen, Zahlungen der Eigentümer der Rechnung zuordnen | [Kosten](kosten.md), [Zahlungen](zahlungen.md) |
| **nach Fälligkeit** | Zahlungsstand prüfen, bei Rückstand nachfragen | [Zahlungen](zahlungen.md) |
| **Jänner / Februar** | Jahresabrechnung des Vorjahres buchen, Abrechnungsblätter versenden | [Jahresabrechnung](jahresabrechnung.md) |
| **jährlich** | Begehung der Gebäude, Rücklagen-Plan aktualisieren | [Rücklage](ruecklage.md) |

!!! warning "Fristen nach kroatischem Recht"
    Wird kein Jahres- bzw. Mehrjahresprogramm beschlossen, müssen die Eigentümer die Rücklage in **fünffacher Höhe** zahlen. Details und Quellen: [News und Recht](news/index.md).

## Menü der Hausverwaltung

| Menüpunkt | Wofür |
|---|---|
| Übersicht / Verteilung | Monatsbeträge je Apartment, Sätze je Haus, Warnungen |
| Gebäude | Häuser mit Rücklagenkonto und Rücklagen-Produkt |
| Apartments | Einheiten mit m², Eigentümern, Haushaltsversicherung |
| Kostenplan | Kostenarten mit Betrag, Zeitraum, Gebäude und Verteilschlüssel |
| Vorschreibung erstellen | Vorschreibungen für einen Monat oder Zeitraum erzeugen |
| Vorschreibungen versenden | E-Mail an die Eigentümer mit allen Anhängen |
| Rundschreiben | Mitteilung an alle oder ausgewählte Eigentümer, übersetzt, mit Anhängen |
| Zahlungsstand | Wer hat was bezahlt, Rückstände |
| Rücklagen / Rücklagen-Planung | Kontostände, Bewegungen, Mehrjahresplan |
| Jahresabrechnung | Ist-Kosten gegen Vorauszahlungen, Abrechnungsblätter |
| Mobil erfassen | Eingangsrechnungen am Handy fotografieren und erfassen |
| Sprachen | Übersetzungen der Dokumente prüfen und ergänzen |
