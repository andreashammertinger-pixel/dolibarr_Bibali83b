# Pitanja i kontakt

??? question "Zašto je moja stopa drukčija nego kod susjeda u drugoj kući?"
    Troškove koji se odnose samo na jednu kuću (osiguranje, vrt, stubište) snosi samo ta kuća. I pričuva ovisi o potrebama pojedine zgrade. Vidi [Razumjeti zaduženje](zaduzenje.md).

??? question "Koji dokument vrijedi – hrvatski ili na mom jeziku?"
    Pravno je mjerodavan **hrvatski izvornik**. Kopija na Vašem jeziku služi za informaciju.

??? question "Nisam dobio/la e-poruku."
    Sva zaduženja nalaze se i online: [Moji računi i dokumenti](racuni.md). Provjerite mapu neželjene pošte i javite nam promijenjenu adresu e-pošte.

??? question "Uplatio/la sam previše / premalo."
    Nije problem – razlika se poravnava sljedećom ratom odnosno u godišnjem obračunu. Za pitanja nam pišite.

??? question "Moji podaci (adresa, e-pošta, OIB) su se promijenili."
    Molimo javite nam – ažurirat ćemo podatke kako bi dokumenti bili ispravno izdani.
