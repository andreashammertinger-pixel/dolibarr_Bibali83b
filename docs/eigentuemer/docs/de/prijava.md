# Anmelden

1. Öffnen Sie **[dolibarr.greenresorts.hr](https://dolibarr.greenresorts.hr)** – am Computer oder am Handy.
2. **Benutzername** und **Passwort** eingeben (haben Sie von der Hausverwaltung erhalten) → *Anmelden*.

!!! tip "Passwort vergessen?"
    Auf der Anmeldeseite *Passwort vergessen?* anklicken – Sie erhalten eine E-Mail mit einem Link. Klappt es nicht, schreiben Sie uns: [office@greenresorts.hr](mailto:office@greenresorts.hr).

## Sprache

Dolibarr zeigt die Sprache Ihres Browsers bzw. die bei Ihrem Zugang hinterlegte Sprache. Möchten Sie eine andere Sprache, schreiben Sie uns kurz – wir stellen sie für Sie ein.

## Am Handy

Dolibarr funktioniert im Browser des Handys. Tipp: Seite zum Startbildschirm hinzufügen (Teilen → *Zum Home-Bildschirm*), dann haben Sie sie wie eine App.

## Hilfe in Dolibarr

Im Menü **Hilfe** öffnet sich diese Seite direkt in Ihrer Sprache.
