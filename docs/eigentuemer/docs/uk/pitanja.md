# Питання та контакт

??? question "Чому моя ставка інша, ніж у сусіда в іншому будинку?"
    Витрати, що стосуються лише одного будинку (страхування, сад, сходова клітка), несе тільки цей будинок. Резервний фонд також залежить від потреб кожної будівлі. Див. [Як читати нарахування](zaduzenje.md).

??? question "Який документ чинний – хорватський чи моєю мовою?"
    Юридичну силу має **хорватський оригінал**. Копія вашою мовою – для інформації.

??? question "Я не отримав(-ла) листа."
    Усі нарахування доступні й онлайн: [Мої рахунки та документи](racuni.md). Перевірте папку «Спам» і повідомте нам, якщо змінилася ваша електронна адреса.

??? question "Я переказав(-ла) забагато / замало."
    Нічого страшного – різниця вирівнюється наступним платежем або в річному розрахунку. З питаннями пишіть нам.

??? question "Мої дані (адреса, e-mail, OIB) змінилися."
    Повідомте нам – ми оновимо дані, щоб документи оформлювалися правильно.
